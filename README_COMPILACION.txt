MATEMATICAS VS ZOMBIS 4.4.4 - BASE MOVIL

Este ZIP NO es un APK ni un IPA. Es un proyecto Capacitor preparado para compilacion.

ANDROID: subir todo el contenido de esta carpeta a la raiz de un repositorio GitHub; abrir Actions > Generar APK Android > Run workflow. Al terminar descargar artifact Matematicas_vs_Zombis_Android_APK. APK debug para pruebas, no distribucion Play Store.

iOS: Actions > Preparar proyecto iOS > Run workflow. Descargar el proyecto Xcode; abrir en Mac, configurar equipo y firma Apple, probar y exportar IPA desde Xcode. No produce IPA firmado automaticamente.

ADVERTENCIAS: Los archivos web proceden de una extraccion previa que tenia cabeceras truncadas. Se repararon los prefijos evidentes de index.html y config.js, pero NO se ha validado el juego en dispositivos, ni que todas las dependencias originales esten presentes. La compilacion puede requerir correcciones adicionales. Si existe el codigo original sin truncar, sustituir www con ese codigo. La URL de Cloud Run en www/config.js es marcador sin configurar; funciones online no operaran hasta definir un servidor real.
